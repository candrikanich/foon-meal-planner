- Bundle ID `com.andrikanich.foon`, Apple team `G374A783RH` (The Recruiting Compass LLC). Chris chose to publish Foon under TRC for now (2026-10-26). - Unit tests run on the macOS destination via `scripts/test.sh` (no simulator, so no contention for the shared sim lock).
